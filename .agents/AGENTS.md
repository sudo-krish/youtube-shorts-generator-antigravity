# Documentation Updates
- **Always Keep Docs in Sync**: Whenever modifying existing code, adding new features, or changing the system architecture, you MUST update the relevant documentation in the `docs/` folder.
- **Consult the Directory Map**: Refer to `docs/directory_map.yaml` to determine the correct folder (Architecture, Rules, Backend, Frontend, Database, or General) and persona guidelines for the documentation you are creating or updating.
- **Continuous Documentation**: Treat documentation updates as an integral part of the task, not an optional afterthought. A task is not complete unless its corresponding documentation is up-to-date.

# Agentic Workflow Planning
- **Always Plan Before Execution**: For any complex request, explicitly outline the Agentic Workflow before taking action. Break down the task into smaller, sequential Agentic Work Packages (AWPs).
- **Define Skill & Role Sequencing**: Clearly map out which skills and personas will be needed at each step of the workflow based on the Routing Matrix.
- **Request Human Review**: If the workflow spans multiple domains or architectural layers, pause and request user feedback on the proposed workflow plan before proceeding with execution.
