# AWP-001: Implement Backend for Part 1 (Project Setup & Script Generation)

## Scope
- `backend/core/db/models.py` (or equivalent schema file)
- `backend/modules/projects/` (new API routes and logic for projects)
- `backend/modules/ai/agents/roles/scriptwriter.py` (refactoring for AI suggestions and draft generation)
- `backend/modules/ai/routes.py` (new API routes for AI generation)

## Goal
Tear down any conflicting legacy models, and establish the new Project API, ScriptBlock API, and DeepSeek-powered prompt/script generation endpoints for the new architecture.

## Acceptance Criteria
- `POST /api/projects` successfully creates a `Project` with metadata and format in SQLite.
- `POST /api/ai/suggest-prompts` returns a list of contextual prompts using `DeepSeekClient`.
- `POST /api/ai/generate-script` generates script content using `DeepSeekClient`.
- `POST /api/script/finalize` correctly parses paragraphs, estimates duration, and persists `ScriptBlock` records.
- Validation commands run without failure.
