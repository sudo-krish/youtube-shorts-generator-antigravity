# Pre-Processor Tools & Context Engine

## Overview
The Antigravity backend completely eliminates AI hallucinations by enforcing a strict **Pre-Processor Architecture**. Before an LLM is ever invoked, deterministic Python scripts scan the VOD, extract physical metadata, and generate a concrete reality map (the Context Engine).

The tools are located in `backend/ai_director/tools/`.

## Core Pre-Processors

### `tracker.py` (AI Object Tracking & CV)
- **Purpose**: Tracks the subject (e.g., the player's crosshair or character) to generate dynamic spatial coordinates (`start_x`, `end_x`) for cropped portrait rendering.
- **Mechanism**:
  - Uses a lightweight **YOLOv8** model (`yolov8n.pt`) via the `ultralytics` library.
  - Extracts frames at 1 FPS to scan for `class 0` (person/subject).
  - Calculates the bounding box center `X`.
  - **Cinematic Smoothing**: Applies a predictive `cv2.KalmanFilter(2, 1)` to the raw coordinates. This smooths out micro-jitters and predicts subject trajectory, creating a true cinematic camera pan that perfectly tracks action without giving the viewer motion sickness.

### `audio_hype.py` (Audio Spike Detection)
- **Purpose**: Prevents the Observer Agent from missing crucial moments in a long VOD by giving it exact timestamps where "loud" things happen (gunfights, screaming, clutches).
- **Mechanism**:
  - Uses `scipy.io.wavfile` to calculate the **RMS energy** (loudness) in 0.5-second chunks.
  - Sorts by RMS energy and extracts the `top_n` loudest spikes.
  - Applies a clustering filter to ignore spikes within 2 seconds of each other.

### `keyframe_mapper.py` (Keyframe Segmentation)
- **Purpose**: Eliminates audio desync and "black frames" when cutting videos.
- **Mechanism**:
  - Uses `ffprobe -select_streams v -show_frames -show_entries frame=pkt_pts_time,pict_type` to map all Keyframes (I-Frames).
  - Mathematically snaps the AI's requested `start_time` cut down to the nearest preceding I-Frame so FFmpeg can slice instantaneously using stream copying (`-c copy`).

### `ocr_reader.py` (Visual Killfeed Reading)
- **Purpose**: Provides raw textual proof of who killed who.
- **Mechanism**:
  - Ingests the timestamp spikes generated by `audio_hype.py`.
  - Extracts a single HD frame at each timestamp via `ffmpeg`.
  - Passes the frame through an advanced ML model, **EasyOCR**.
  - Returns a dictionary mapping the timestamp to the exact text on the screen, forcing the Observer Agent to base its "ACE" or "CLUTCH" narrative on verified data rather than guessing.

### `web_scraper.py` (Trend Simulation)
- **Purpose**: Injects cultural relevance into the Scriptwriter.
- **Mechanism**: Simulates fetching live external trending data based on the UI's `Game Name` and `Region` inputs to ensure the narrative hooks align with current YouTube/TikTok meta.

### `sfx_indexer.py` & `audio_indexer.py` (Library Scanners)
- **Purpose**: Prevents the Director from hallucinating fake `.mp3` files.
- **Mechanism**: Scans the physical `downloads/sfx` and `downloads/audio_library` directories. Returns a JSON map of available files and their semantic vibes so the Director is forced to pick a valid filename.

### `math_validator.py` (Sanity Checking)
- **Purpose**: Mathematically proves the Editor Agent's FFmpeg breakdown is physically possible.
- **Mechanism**: 
  - Validates that `end_time > start_time`.
  - Validates that `visual_punch_in_timestamps` are within the bounds of the specific phase duration.
  - Detects if an effect's duration exceeds the length of the clip.
  - Auto-corrects overlapping transitions.
